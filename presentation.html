The Challenge

Why This Platform Was Needed

The community faced real coordination problems that made collective development difficult, slow and untransparent.

Disconnected Diaspora

Members abroad had no reliable way to stay connected to village decisions or contribute meaningfully.

No Financial Transparency

Donations collected informally with no public tracking, creating distrust among potential donors abroad.

No Payment Infrastructure

No secure way to accept international donations — MoMo, PayPal and cards were not integrated.

No Governance Tools

Elections, petitions and polls happened informally with no secure or verifiable process.

Dying Cultural Heritage

The Ngiemboon language and traditions were undocumented — especially for younger diaspora generations.

Scattered Communication

News and updates shared via WhatsApp only — inconsistent, unarchived and unreliable.

Architecture Highlights

  • REST API with JWT auth and role-based access (admin / leader / member)
  • Password hashing with bcrypt, secure refresh token rotation
  • All media via Cloudinary CDN with auto-format & quality optimisation
  • Video meetings via Daily.co — host privileges for admin/leader roles
  • Service worker for push notifications — works on mobile browsers
  • PostgreSQL + Prisma ORM — typed schema, migrations, full relations
  • Rate limiting, CORS, Helmet security on all endpoints
